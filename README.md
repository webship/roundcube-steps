# roundcube-steps

Cucumber step definitions for Roundcube, the open-source webmail (the login, the mail list, a message and its
preview, writing and sending a mail, folders, the address book with its groups, and the settings: identities,
responses and preferences), with [webship-js](https://webship.co/docs/webship-js/2.0.x), a BDD browser automation
harness built on Playwright and Cucumber-js.

The steps, their features, the test site and CI come with the first release, `2.0.0`.
